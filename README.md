# fiat santa

*let there be santa* — the family's Secret Santa for Sailfish OS.

- Names of everyone taking part
- Pairs who must not draw each other, kept apart both ways
- A price limit, if you want one
- The draw makes one ring through everyone where it can, so nobody draws the
  person who drew them
- Pass the phone: everyone taps their own name, confirms, looks, hides
- Or send codes: one message per person, by SMS, by email or copied into
  whatever the family uses. Messages and Email open with the text filled in and
  you pick the recipient there. The message carries a link to
  [munkstolen.se/secret-santa-c.html](https://munkstolen.se/secret-santa-c.html)
  with the code in it, so one tap shows the draw; the code also opens in
  fiat santa on any phone, under "I have a code"
- The cover shows how many are in the draw and how many have looked, never who
  got whom

The codes use the same format as the web version, so a code made here opens
there and the other way round. They hide a name from
a glance; they are not encryption.

In English, Swedish, French, German, Russian, Spanish, Portuguese, Italian,
Chinese and Japanese, following the phone. The code page follows the browser.

Everything stays on the phone. No account, no network, no permissions.

Part of the fiat family — small, focused Sailfish OS apps that do one thing
plainly.
